# freeze & talk – Link in Bio

Statische Link-in-Bio-Seite für den Podcast **freeze & talk** (freezeclub Balingen).

## Inhalt
- `index.html` – die Seite (self-contained, statisch)
- `assets/` – Logo, Teilen-Vorschaubild (`og-image`), QR-Code + Studio-Karte

## Hosting
Reines HTML/CSS/JS – einfach ausliefern (z. B. GitHub Pages).
Nach dem Deploy in `index.html` die `og:image`- und `og:url`-Meta-Tags auf die
absolute Domain umstellen, damit Link-Vorschauen (WhatsApp/Instagram) funktionieren.
